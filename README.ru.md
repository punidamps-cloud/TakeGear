# TakeGear

**Таймлайн-секвенсер тейков для Cinema 4D 2024 / 2025 / 2026** — мультитрековый редактор в стиле монтажных программ, который определяет, какой Take активен на каком кадре, оставаясь полностью внутри нативного Take- и рендер-воркфлоу Cinema 4D.

[English version →](README.md)

![TakeGear UI](docs/TakeGearUI.png)

🎬 **[Демо-видео](docs/TakeGearDemo.mp4)**

> TakeGear — **не** видеоредактор (не режет отрендеренное видео) и **не** система ретайминга: анимация сцены остаётся на глобальной таймлинии C4D. Тайминг камеры при необходимости можно привязать к клипу.

---

## Возможности

- **Мультитрек-таймлайн тейков**: drag / trim / split / duplicate, мультивыделение (Shift+клик, рамка), групповые операции, Ctrl+C/V, ripple delete (`Shift+Del`), снап, маркеры, IN/OUT
- **Авто-переключение тейков** при скрабе, плейбеке, превью и рендере; вне клипов — откат на Main Take
- **Камеры**: имя и ключи камеры на каждом клипе; ручка смещения ключей по времени (с живым диапазоном); Camera Follow; мастер «Create Takes From Cameras»
- **Рендер**: Render Edit (нативные Marked Takes) и Render Now (батч через Render Queue) + живые статусы рендера в Sheet
- **Продакшн-трекинг**: Sheet-таблица, статусы Todo→Approved, заметки, экспорт шот-листа в CSV
- **Референс-аудио**: волна WAV, drag-смещение, слышно при воспроизведении
- **HUD во вьюпорте**, миниатюры кадров в клипах, тёмный flat-UI со скруглениями и hover
- Все данные хранятся в документе C4D, полный undo

## Установка

1. Скачайте из [Releases](../../releases) zip **под вашу версию Cinema 4D** — сборки между мажорными версиями не взаимозаменяемы:

   | Cinema 4D | Файл | Статус |
   |---|---|---|
   | 2026.x | `TakeGear_vX.X.X_Win_C4D2026.zip` | основная, полностью протестирована |
   | 2025.x | `TakeGear_vX.X.X_Win_C4D2025.zip` | собрана против SDK 2025.3 |
   | 2024.x | `TakeGear_vX.X.X_Win_C4D2024.zip` | собрана против SDK 2024.5 |

2. Распакуйте папку `TakeGear` в каталог плагинов, например:
   `%APPDATA%\Maxon\Maxon Cinema 4D 2026_XXXXXXXX\plugins\TakeGear\`
3. Перезапустите C4D → **Extensions → TakeGear**

Windows (macOS — сборка из исходников). Один кодбейс покрывает 2024/2025/2026 через `source/tc_compat.h`.

## Быстрый старт

1. Создайте несколько тейков (панель **Source Takes** или Take Manager)
2. Перетащите тейк на дорожку — или нажмите `A` для клипа из текущего тейка
3. Скрабьте по линейке — тейки переключаются во вьюпорте живьём
4. Задайте диапазон `I`/`O`, жмите `Space` или **Preview Edit**
5. **Render Now** — батч-рендер всех клипов через Render Queue

## Горячие клавиши (работают в RU и EN раскладках)

`Space` плей/стоп · `A` клип · `S` split · `D` дубль · `F` фокус · `M` маркер · `I`/`O` IN/OUT · `H` fit · `←`/`→` сдвиг (Shift=10) · `Del` удалить · `Shift+Del` ripple · `Ctrl+C/V` копия/вставка · `Ctrl+A` выделить всё

Мышь: ЛКМ по линейке — скраб; ЛКМ по клипу — перенос/трим; полоса камеры — смещение ключей; Shift+клик — мультивыделение; рамка по пустому месту; Ctrl+драг — дубль; ПКМ — меню, ПКМ-драг — зум; СКМ/Alt — пан; колесо — зум (Shift — пан, Ctrl — высота треков).

## Ограничения

- Клипы ссылаются на тейки **по имени** (переименование через TakeGear перепривязывает автоматически)
- Аудио — только несжатый PCM WAV (16/8 бит)
- Миниатюры рендерятся Standard-рендером в низком разрешении
